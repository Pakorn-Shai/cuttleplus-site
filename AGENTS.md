# Repository workflow

- Publish this project to `https://github.com/Pakorn-Shai/cuttleplus-site`.
- Create and push a new `agent/*` branch for each delivery; never push directly to `main`.
- The user will review and merge the branch on GitHub.
- Treat the Knowledge Hub source tree as the intended replacement payload for that repository. Do not ask for the repository URL again unless the user explicitly changes the target.
- Never include `.env`, `.env.test`, dependencies, generated build output, uploaded media, or test artifacts in a commit.
